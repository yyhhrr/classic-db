# C60WOW 世界数据库修复

这组迁移整理了 C60WOW 在 2026 年 10 月和 11 月验证过的世界数据修复，覆盖团本和地下城、任务剧情和条件、EventAI 与法术列表、刷新和巡逻、物品掉落以及简体中文本地化。部分技能和事件使用 C60WOW 的 CMaNGOS 脚本。

## 安装

使用配套的 `yyhhrr/mangos-classic`，以包含萨弗隆先驱者修复的 `f51c43910` 为参考版本。在 `InstallFullDB.config` 中启用 `DEV_UPDATES="YES"`。Classic-DB 安装器会在核心更新、实例数据、ScriptDev2、ACID 和本地化都载入后，依文件名顺序执行本目录的 SQL。

整组迁移以新装或重建的世界库为目标。已有服务器上的增量部署沿用各补丁的范围核对和回滚流程。核心架构迁移由核心仓库管理。账号、角色进度、缓存和 PlayerBots 表由各自数据库或模块管理。

## 验证

使用 MySQL 5.7、新装的 Classic-DB `9846159d` 和配套核心进行验证。初次整理的 122 份 SQL 按安装顺序严格导入。新增的萨弗隆迁移在 MySQL 5.7 隔离库验证了重复执行及回滚。复核了熔火之心关键法术、任务 1324 的固定哨兵、乔基姆·布伦洛的商人菜单和库尔森药剂师的治疗列表。对比导入前后的刷新关联，确认这批迁移未新增孤儿记录。新增脚本绑定均能在配套核心找到实现。

历史上游合并按当前库重新比对。现行记录已包含的改动无需重复录入。历史快照与现行 ID、路径或内容冲突的行沿用现行记录。安其拉废墟缺失的正向脚本由已部署的世界数据与对应回滚记录重建。
